## 宝塔面板在雨云上怎么开起来

从下单到网站能打开，实际要做的是七步。这套流程有公开的操作记录可查，演示用的是香港节点。

**第一步，下单时选预装。** 在购买页找到“选择预装系统和 app”，把宝塔面板勾上。已有的操作记录里，有用户拿到的镜像是“宝塔面板 7.9 [Centos8/LNMP]”，也就是系统加面板加 LNMP 环境一起预装好了。这类镜像版本可能随官方更新变化，下单页显示什么就是什么，不要假定一定是 7.9。

**第二步，等待部署。** 提交订单后系统自动装，不需要人守着。

**第三步，从控制台进面板。** 创建成功后，控制台里有一个“管理宝塔面板”的按钮，点它直接跳到面板登录页。这一步省掉了自己找面板地址、找随机入口后缀的麻烦。

**第四步，添加站点。** 登录面板后进“网站”，点 PHP 项目添加，把域名填进去提交。此时站点目录已经建好，但里面是空的。

**第五步，上传网站文件。** 进站点根目录，把程序压缩包传上去再解压。如果是 WordPress，也可以先传压缩包解压，再访问域名走安装向导。

**第六步，解析域名。** 到域名服务商那里加一条 A 记录，指向服务器的公网 IP。用 Cloudflare 的话就是在 DNS 里加 A 记录，保存后等生效。

**第七步，申请 SSL 证书。** 在宝塔的网站设置里找到“SSL 证书”，选 Let's Encrypt，把要签的域名全选上，点申请，等验证通过。证书会自动续期，这一步做完整站就是 HTTPS 了。

## 建站前必须知道的四个坑

**坑一：国内节点要备案，周期约 20 天。** 宿迁、宁波、十堰这些机房，域名必须完成 ICP 备案才能绑定访问，流程走下来一般 20 天左右。这 20 天里服务器是买着的，钱照扣。不想等就选香港或美国节点，买完解析完就能开站。香港三区全国平均延迟约 35ms，跟国内节点的体感差距没有想象中大，这是拿时间换延迟的取舍。

**坑二：默认共享 IP 走 NAT，80/443 可能受限。** 大部分套餐默认分配共享 IP，通过端口映射对外提供服务。做普通网站不一定出问题，但如果你的程序或某些功能强依赖标准的 80/443 端口，共享 IP 会有功能限制。这一点在教程类文章里几乎没人提，但它决定你能不能正常建站，买之前值得先问清楚自己的程序有没有这个需求。

**坑三：独立 IP 要另外买。** 需要独立 IP 得额外付费，一般每月 30 元。这个价格会明显改变总成本：18 元的入门套餐加 30 元独立 IP，实际支出接近翻倍。是否需要，取决于坑二里那个问题。

**坑四：退款只退到余额，而且只有 3 次。** 7 天无理由退款是有的，控制面板可以自助退订，但退的钱进账户余额，提不到支付宝或微信，只能在雨云继续消费。次数上限 3 次，领过消费返利积分的订单、超时订单、日付产品都不支持退款。这意味着试错预算要一次算清，别把 3 次机会花在反复换套餐上。

## 几个真实会被问到的问题

**能不能不买服务器就用宝塔面板？** 宝塔面板本身是装在服务器上的软件，需要一台机器承载。雨云的虚拟主机产品支持宝塔面板，算是门槛最低的一种；云应用 RCA 不需要自己买服务器，但它是容器平台，不是传统意义的宝塔面板，而且仍在内测。

**香港节点要不要备案？** 不要。香港和美国节点都不需要 ICP 备案，买完解析就能访问。代价是延迟比国内节点高一些，香港三区约 35ms。

**面板进不去怎么办？** 先确认服务器是不是还在部署中，部署没完成时面板入口是打不开的。如果部署完成仍然进不去，走工单。雨云工单一般几小时内回复，节假日或半夜提交可能要等到次日；官方论坛也比较活跃，很多问题能搜到现成答案。具体到端口、防火墙、安全组的排查步骤，各家环境不一样，这里不猜。

**退款怎么算？** 7 天内可申请，控制面板自助操作，退到账户余额，不能提现，每人 3 次机会。领过返利积分的订单、超时订单、日付产品不支持退款。
